# Kit de arranque — Serialo Planillas

Contenido para copiar encima de un proyecto nuevo de Laravel 13 (starter kit Vue). Instrucciones paso a paso: **INSTALAR.md**.

- `CLAUDE.md` y `docs/` — contexto para Claude Code y documentación del producto
- `.claude/` — comandos `/siguiente-tarea`, `/nuevo-modulo`, `/validar-calculo`, `/actualizar-roadmap` y permisos
- `app/Domain` — motor de cálculo y generadores PLAME (PHP puro, probado)
- `app/Services`, `app/Models`, `app/Enums` — capa Laravel
- `database/migrations`, `database/seeders` — esquema, catálogos y datos demo ficticios
- `tests/Unit` — 8 tests (incluye un caso real validado al céntimo)
